# Frenciniz Admin Android

Sadece `https://www.frenciniz.com/admin-login` ve yönetim rotalarını uygulama içinde açan Android WebView uygulamasıdır.

- Şifre veya API anahtarı APK içine gömülmez.
- Oturum, frenciniz.com güvenli çereziyle saklanır.
- Müşteri sitesi uygulama içinde açılamaz.
- Harici bağlantılar telefonun varsayılan uygulamasına yönlendirilir.
- HTTP bağlantıları ve SSL hataları engellenir.
- Admin girişi yapıldıktan sonra yeni ilgili ziyaretçi ve canlı destek mesajları 15 saniyelik aralıklarla bildirilir.
- Bildirime dokunulduğunda doğrudan Canlı Destek ekranı açılır.
- Android bildirim izni verilmelidir; uygulamanın sürekli takip bildirimi kapatılmamalıdır.

Derleme için Android SDK 35 ve JDK 17 gerekir.
